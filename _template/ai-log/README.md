# ai-log/

เก็บบทสนทนากับ AI **ทั้งหมด** ของงานนี้ไว้ในโฟลเดอร์นี้ แชตละ 1 ไฟล์ ข้อความแรกของทุกแชตต้องเป็น tutor prompt ของรายวิชา
tutor prompt และระดับคำถาม L0–L3: https://github.com/kasikrit/310-126-OOP-2-69-student/blob/main/AI-tutor-prompt.md

## วิธี export
- **ChatGPT / Claude / Gemini:** คัดลอกข้อความบทสนทนาทั้งหมด (ทั้งคำถามของเราและคำตอบของ AI ตามลำดับ) วางในไฟล์ข้อความ `ai-log/<เครื่องมือ>-<วันที่>.md` (เช่น `ai-log/chatgpt-2027-01-12.md`) หรือ `.txt` ด้วย VS Code แล้วเปิดไฟล์ตรวจว่ามีข้อความครบก่อน commit
- แชตละ 1 ไฟล์ ห้ามตัดหรือแก้ข้อความ
- **ส่งได้เฉพาะไฟล์ข้อความ `.md` หรือ `.txt` เท่านั้น** ห้ามส่ง PDF, รูปภาพ (screenshot) และไฟล์ export ดิบ (zip จากเมนู Export data, JSONL, โฟลเดอร์ session) เหตุผล: PDF ที่สั่งพิมพ์จากหน้าแชต (เช่น Microsoft Print to PDF) มักออกมาเป็นหน้าว่างหรือเป็นรูปที่ค้นข้อความไม่ได้ และไฟล์ดิบมีข้อมูลส่วนตัว (อีเมล, การตั้งค่า, path ในเครื่อง) ติดมา ส่งรูปแบบอื่น = ข้อ tutor prompt / log (10 คะแนน) ได้ไม่เกินครึ่ง และถ้าเปิดอ่านบทสนทนาไม่ได้ จะถือว่าไม่มี log
- ไม่ใช้ AI เลย: สร้างไฟล์ `ai-log/NONE.md` เขียนว่า "งานนี้ไม่ได้ใช้ AI" แล้ว **TA เรียก viva ทุกคน** และใช้คะแนน viva เป็นคะแนนส่วนการเรียนรู้ 50 คะแนน (แทนการตรวจ `ai-log/`)
