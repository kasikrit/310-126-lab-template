# 310-126 OOP: repo งาน

repo นี้สร้างจาก template ของรายวิชา 310-126 OOP (2/69) ดูขั้นตอนเต็มใน [Lab 0 handout](https://github.com/kasikrit/310-126-OOP-2-69-student/blob/main/Lab0-handout.md)

1. เพิ่ม `kasikrit` เป็น collaborator (Settings → Collaborators → Add people) **ห้ามลบคำเชิญจนจบภาคการศึกษา**
2. ทำงานตามลำดับ: `PROCESS.md` ขั้น 1 (ก่อนเปิด AI และก่อนเขียนโค้ด) → ใช้ AI tutor และเก็บบทสนทนาใน `ai-log/` → เขียนโค้ด → ทดสอบ → สะท้อนการเรียนรู้ และ commit แยกทุกขั้น
3. ส่ง SHA เต็ม 40 ตัว (`git rev-parse HEAD`) ผ่าน Google Form ส่งงานภายใน deadline
