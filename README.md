# 310-126 OOP: repo งาน

repo นี้สร้างจาก template ของรายวิชา 310-126 OOP (2/69) ดูขั้นตอนเต็มใน [Lab 0 handout](https://github.com/kasikrit/310-126-OOP-2-69-student/blob/main/Lab0-handout.md)

1. เพิ่ม collaborator 3 บัญชี: `kasikrit` (อาจารย์) + TA 2 คน `tonethana` และ `kroekchanwit` (Settings → Collaborators → Add people) **ห้ามลบคำเชิญจนจบภาคการศึกษา**
2. กรอก `PROCESS.md` ขั้น 1 แล้ว commit + push **ก่อนเปิด AI และก่อนเขียนโค้ด**
3. ใช้ AI แบบแชตกับ tutor prompt และเก็บบทสนทนาใน `ai-log/` เป็น `.md` หรือ PDF (ไม่ใช้ AI: `ai-log/NONE.md` และต้อง viva)
4. เขียนโค้ด แล้วรันด้วย `java Run.java <ชื่อคลาส>` เท่านั้น (ผลถูกบันทึกลง `outputs.txt` เอง ห้ามแก้ `outputs.txt` และ `Run.java`) และ commit หลังรันแต่ละครั้ง
5. ติ๊กคำรับรองท้าย `PROCESS.md` ใน commit สุดท้าย แล้วส่ง SHA เต็ม 40 ตัว (`git rev-parse HEAD`) ผ่าน Google Form ส่งงานภายใน deadline
